# SQL Basics

## What is SQL?

SQL (Structured Query Language) is used to interact with databases.

It allows you to:

* retrieve data
* insert data
* update data
* delete data

---

## Database Structure

* **Database** → collection of data
* **Table** → organized data
* **Row** → record
* **Column** → attribute

Example:

| id | username | password |
| -- | -------- | -------- |
| 1  | admin    | hash123  |

---

## Keys

* **Primary Key** → unique identifier (e.g., id)
* **Foreign Key** → links tables together

---

## SQL vs SQLi

* SQL → used by developers
* SQL Injection → used by attackers

---

## Where SQL is used

* Websites (login systems)
* Applications
* APIs

---

## Important Concept

SQL queries are often built using user input → this is where vulnerabilities happen.
