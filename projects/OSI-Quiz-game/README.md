# OSI Model Quiz Game

## Overview

A Python-based command-line quiz game designed to test knowledge of the OSI Model.
The game randomly selects 50 questions from a dataset and scores the user based on correct answers.

---

## Features

* 50 randomized questions per session
* Multiple-choice format (A, B, C, D)
* Score system (2 points per correct answer)
* Immediate feedback after each question
* Final performance evaluation

---

## Technologies Used

* Python 3
* JSON (for storing questions)

## How to Run

### 1. Clone the repository

```bash
git clone https://github.com/geratofe/cybersecurity-notes.git
cd cybersecurity-notes/OSI-model/OSI-Quiz-game
```

### 2. Make script executable (optional)

```bash
chmod +x quiz.py
```

### 3. Run the program

```bash
./quiz.py
```

Or:

```bash
python3 quiz.py
```
